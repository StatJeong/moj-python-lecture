2. 데이터 다루기 (pandas)

Colab에서 실습 노트북 열기

엑셀처럼 행과 열로 된 표 데이터를 파이썬에서 다룰 때는 pandas를 씁니다. 이 장에서는 수용자 데이터(inmates.csv)를 읽고, 원하는 열과 행을 고르고, 집계하고, 다른 표와 합치는 방법을 익힙니다.

경고GitHub 파일은 raw 주소로 읽습니다

GitHub 화면 주소(https://github.com/.../blob/...)를 그대로 넣으면 웹페이지를 읽으려다 ParserError: Error tokenizing data가 납니다. 파일 화면의 Raw 버튼을 누르면 나오는 https://raw.githubusercontent.com/... 주소를 씁니다.

노트import 칸을 먼저 실행하기

NameError: name 'pd' is not defined가 나면 import pandas as pd가 있는 칸을 실행하지 않은 것입니다.

  • import pandas as pd는 pandas를 불러와 pd라는 짧은 이름으로 쓰겠다는 뜻입니다.
  • pd.read_csv()는 CSV 파일을 읽어 표(DataFrame)로 만듭니다.

내 컴퓨터에 있는 파일을 읽을 때는 Colab 왼쪽의 폴더 아이콘을 눌러 파일을 올린 뒤 파일 이름만 씁니다. 공공기관에서 받은 한글 CSV 파일은 인코딩이 달라서 글자가 깨질 때가 많습니다. 그때는 encoding="cp949"를 붙입니다. 엑셀 파일은 pd.read_excel()로 읽습니다.

표 = pd.read_csv("내파일.csv", encoding="cp949")
표 = pd.read_excel("내파일.xlsx")
경고한글이 깨지거나 UnicodeDecodeError가 날 때

공공기관이나 엑셀에서 저장한 CSV는 cp949(또는 euc-kr) 인코딩인 경우가 많습니다. 그냥 읽으면 UnicodeDecodeError: 'utf-8' codec can't decode byte ...가 납니다. encoding="cp949"를 붙여 다시 읽습니다.

경고Colab에 올린 파일은 연결이 끊기면 사라집니다

왼쪽 폴더 아이콘으로 올린 파일은 임시 공간에 저장됩니다. 연결이 끊기거나 세션을 다시 시작하면 지워지므로 원본은 내 컴퓨터에 두고, 결과 파일은 바로 내려받습니다.

중요실제 업무 데이터는 Colab에 올리지 않기

Colab은 구글 서버에서 실행됩니다. 실제 수용자 정보가 담긴 파일은 Colab에 올리지 않고, 기관의 내부 분석 환경과 보안 지침을 따릅니다.

없는 열 이름을 쓰면 KeyError: '나 이'처럼 오류가 납니다. 열 이름 앞뒤에 보이지 않는 공백이 붙은 파일도 많습니다. 수용자.columns로 정확한 이름을 확인하고, 필요하면 수용자.columns = 수용자.columns.str.strip()으로 앞뒤 공백을 지웁니다.

노트대괄호 한 겹과 두 겹

수용자["나이"]는 열 하나(Series), 수용자[["나이"]]는 열 하나짜리 표(DataFrame)입니다. 여러 열을 고를 때는 반드시 두 겹입니다.

힌트수용자.나이 처럼 점으로 꺼내기

수용자.나이도 동작하지만, 열 이름에 띄어쓰기가 있거나 count처럼 pandas 기능 이름과 같으면 원하는 열이 나오지 않습니다(수용자.count는 열이 아니라 기능). 대괄호 방식을 기본으로 씁니다.

2.4 행 고르기 (필터)

조건에 맞는 행만 고를 수 있습니다. 먼저 조건만 써 보면 행마다 True / False가 나옵니다.

수용자["나이"] < 30
0     True
1    False
2    False
3     True
4    False
5    False
6     True
7    False
8    False
9    False
Name: 나이, dtype: bool

이것을 다시 대괄호에 넣으면 True인 행만 남습니다.

수용자[수용자["나이"] < 30]
수용번호 시설 성별 나이 죄명 형기_개월 입소일 경비처우급 직업훈련 상담횟수 징벌횟수 최근상담메모
0 1001 A교도소 남 24 절도 24 2025-03-12 S3 N 2.0 2 수면이 부족하고 예민해졌다고 말함
3 1004 B교도소 남 28 폭력 30 2025-01-15 S4 N 1.0 3 작업장에서 다른 수용자와 갈등이 반복된다고 호소함
6 1007 C교도소 여 26 사기 12 2026-02-03 S3 Y NaN 1 NaN

조건 두 개를 함께 쓸 때는 and 대신 &(그리고), or 대신 |(또는)를 쓰고 조건마다 괄호를 칩니다.

수용자[(수용자["죄명"] == "사기") & (수용자["나이"] >= 40)]
수용번호 시설 성별 나이 죄명 형기_개월 입소일 경비처우급 직업훈련 상담횟수 징벌횟수 최근상담메모
2 1003 B교도소 여 45 사기 24 2025-06-20 S2 Y 6.0 0 가족 접견 이후 정서가 안정됨
9 1010 C교도소 남 58 사기 42 2024-05-30 S2 Y 7.0 0 직업훈련(제과) 수료 후 관련 분야 취업을 희망함
경고and 대신 &, 조건마다 괄호 
수용자[(수용자["나이"] < 30) and (수용자["징벌횟수"] > 0)]
수용자[수용자["나이"] < 30 & 수용자["징벌횟수"] > 0]

두 줄 모두 ValueError: The truth value of a Series is ambiguous...가 납니다. 첫 줄은 and를 써서, 둘째 줄은 괄호가 없어서입니다. &는 <보다 먼저 계산되므로 조건마다 괄호가 필요합니다.

힌트일부 글자가 들어 있는 행 찾기

==는 값이 정확히 같아야 합니다. "사기 "처럼 공백이 하나 붙어도 다른 값입니다. 일부 글자가 들어 있는지 확인할 때는 .str.contains()를 씁니다.

수용자[수용자["최근상담메모"].str.contains("출소", na=False)]

na=False는 빈 메모를 거짓으로 처리하라는 뜻입니다. 빠뜨리면 pandas 버전에 따라 ValueError: Cannot mask with non-boolean array containing NA / NaN values가 납니다.

pd.to_datetime("01/02/2026")은 1월 2일로 읽힙니다(월/일 순서). 2월 1일이라는 뜻이었다면 틀린 값이 됩니다. 형식을 알 때는 pd.to_datetime(열, format="%d/%m/%Y")처럼 직접 지정합니다.

엑셀에서 온 날짜가 45000 같은 숫자로 보이면 엑셀 일련번호입니다. pd.to_datetime(45000, unit="D", origin="1899-12-30")로 바꾸면 2023-03-15가 됩니다.
