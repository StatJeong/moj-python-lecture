# 실습용 가상 교정 데이터

모든 값은 강의를 위해 만든 가상 데이터이며 실제 수용자, 시설과 관계가 없습니다. 파일은 UTF-8 CSV입니다.

| 파일 | 크기 | 설명 |
|---|---|---|
| inmates.csv | 10행 12열 | 수용자 데이터 |
| facilities.csv | 4행 3열 | 시설현황 데이터 |

두 표는 `시설` 열로 연결됩니다.

## inmates.csv

| 열 | 설명 | 예시 |
|---|---|---|
| 수용번호 | 수용자 식별번호 | 1001 |
| 시설 | A교도소, B교도소, C교도소 | A교도소 |
| 성별 | 남 / 여 | 남 |
| 나이 | 만 나이 | 24 |
| 죄명 | 절도, 사기, 횡령, 폭력, 마약 | 절도 |
| 형기_개월 | 형기 (개월) | 24 |
| 입소일 | YYYY-MM-DD | 2025-03-12 |
| 경비처우급 | S1(개방) ~ S4(중경비) | S3 |
| 직업훈련 | Y / N | N |
| 상담횟수 | 누적 상담 횟수 | 2 |
| 징벌횟수 | 누적 징벌 횟수 | 2 |
| 최근상담메모 | 가장 최근 상담의 짧은 메모 | 수면이 부족하고 ... |

## facilities.csv

| 열 | 설명 | 예시 |
|---|---|---|
| 시설 | A교도소 ~ D교도소 | A교도소 |
| 정원 | 수용 정원 | 1200 |
| 현원 | 1일 평균 수용인원 | 1523 |

## 실습에 쓰도록 미리 넣어 둔 장치

1. 결측치: 1007번은 상담횟수와 최근상담메모가 비어 있습니다. 상담횟수 평균은 9명 기준으로 계산되고(4.22), 회귀분석에서도 이 행이 빠져 관측치가 9개가 됩니다.
2. 날짜 계산: 입소일에 형기_개월을 더하면 출소예정일이 나오고, 모두 2026년 11월 이후입니다.
3. 집계: 시설별 징벌횟수 합계는 A 5, B 4, C 1입니다.
4. 병합: inmates.csv에 facilities.csv를 시설 기준으로 붙이면 10행이 유지되고 정원, 현원 열이 붙습니다. 수용률은 A 126.9, B 120.0, C 115.0입니다. D교도소는 수용자 데이터에 없어서 결과에 나타나지 않습니다.
5. 회귀
   - 징벌횟수 ~ 상담횟수 (선형회귀): 기울기가 음수 (관측치 9개)
   - 징벌여부 ~ 나이 (로지스틱 회귀): 정상 추정
   - 징벌여부 ~ 직업훈련: 직업훈련 N인 5명이 모두 징벌을 받아 제대로 추정되지 않음 (완전 분리)
6. 비율 평균: 시설 4곳 수용률의 단순평균(124.2)과 전체 현원 / 전체 정원(122.3)이 다릅니다.

10행짜리 데이터라 회귀 결과는 코드 작동을 확인하는 용도입니다.
